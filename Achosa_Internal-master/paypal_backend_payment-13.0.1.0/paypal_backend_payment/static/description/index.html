Enterprise

It enables backend payment method by using Paypal Backend Payment

Key Features

  • Paypal backend payment method can be creatd in payment acquirers.
  • Enables backend payment method.
  • Payment method configuration required.
  • Supported by all browsers.

Paypal Backend Payment Configuration

  • Navigate to the Invoicing and click on the Configuration menu.
  • Open Payment Acquirers sub-menu and configure our payment method.

Sale Order

  • Now, we will create sale order and confirm our sale order.
  • After confirming sale order, Pay with Paypal button will automatically come.
  • Now, we will click on Pay with Paypal button.
  • Page will be automatically re-direct on Paypal payment page.

Paypal Payment Page

  • Here we can manage our payment methods and click on Continue button.
