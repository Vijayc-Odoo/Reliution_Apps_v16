# Overview
Directory structure:
```
/home/odoo/src/user/
               └── scripts
                   ├── README.md
                   ├── createLogDir.sh
                   ├── script1.sh
                   ├── script2.sh
                   └── logs
                       ├── .gitignore
                       ├── logfile1.log
                       └── logfile2.log
```
This directory (`~/scripts/`) should contain scripts to automate backend tasks, this `README.md`, a directory to contain logs generated by those scripts, and a `createLogDir.sh` script to rebuild the logs folder.
The `logs` folder itself should show up in commits, but its contents should not, due to the `.gitignore` it contains which tells git to ignore all files in its directory except for itself. It is safe to delete the log files, and even the logs directory, as the `createLogDir.sh` script will rebuild the `./logs/` directory and it's `.gitignore` file when executed. Doing so may mean that the refreshing of the `logs` directory shows up in some commits.

## detect-rebuild.sh
This script is designed to be run periodically in order to detect when a branch has been rebuilt and then execute some arbitrary operations.
Relevant directory structure:
```
/home/odoo/src/user/
               └── scripts
                   ├── README.md
                   ├── createLogDir.sh
                   ├── detect-rebuild.sh
                   └── logs
                       ├── .gitignore
                       └── pgdb.log
```
This script appends the current `PGDATABASE` name and the Unix Timestamp to the end of the `pgdb.log` file, seperated by a space every time it is run. If the relevant directories and files do not yet exist, they are created and filled in. `pgdb.log` is then used to compare the current `PGDATABASE` name (found with `printenv PGDATABASE`) to the last logged `PGDATABASE` name. If they're different, then the branch must've been rebuilt, and the script can then run whatever code we need it to run.
The `BRANCH` variable should be set to the human readable part of the name returned by `printenv PGDATABASE` that corresponds to the name of the branch. For example, `qa-uat`, or `training`.
This script was originally developed and tracked [here](https://github.com/bjthres1/restyn-odoo-scripts). There may be some CRLF vs LF issues with the script files.
